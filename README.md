# Synapse

Synapse is a production-grade, high-performance, minimalist long-term knowledge retention platform built with Angular 21. It serves as a centralized "second brain" for engineers, transforming deep-dive technical notes into interactive active-recall flashcards.

The project is architected with a Design Token philosophy—avoiding utility-first CSS frameworks in favor of a custom, highly maintainable styling system based on Angular Material 3 and modern SCSS.

## 🧠 The Philosophy
The name Synapse represents the firing of connections between complex concepts. Most note-taking apps are graveyards for information; Synapse is designed for retention. By combining the flexibility of .md files with a Signal-based flashcard engine, it ensures that your knowledge in Java, Spring Boot, Machine Learning, and Gen AI remains "hot."

This project was generated using [Angular CLI](https://github.com/angular/angular-cli) version 21.1.3.

## Development server

To start a local development server, run:

```bash
ng serve
```

Once the server is running, open your browser and navigate to `http://localhost:4200/`. The application will automatically reload whenever you modify any of the source files.
